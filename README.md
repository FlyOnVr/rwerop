# Lunar Discord Bot

1. Open this folder in PyCharm (File > Open).
2. Create a venv when prompted (or Settings > Project > Python Interpreter > Add).
3. Install deps: `pip install -r requirements.txt`
4. Edit `.env` and set `DISCORD_TOKEN=` to your bot token.
5. Run `main.py`.

In the Discord Developer Portal, enable the **Message Content Intent** for the bot.
Never commit `.env` (it's in .gitignore).
